# wasmga.me

Games that run in the browser on WebAssembly: Flash, retro, modern ports and
games of our own. Play at [wasmga.me](https://wasmga.me).

## Our code

- [games](https://github.com/wasmga-me/games): the games made for the site, in C and Rust
- [wasmgame-wg-c](https://github.com/wasmga-me/wasmgame-wg-c): the engine of our C games
- [wasmgame-wg](https://github.com/wasmga-me/wasmgame-wg): the engine of our Rust games

## Ports

Each fork's `wasmgame` branch holds our changes and build files:

- [mindustry-wasm](https://github.com/wasmga-me/mindustry-wasm/tree/wasmgame): [Mindustry](https://wasmga.me/games/mindustry)
- [endless-sky-wasm](https://github.com/wasmga-me/endless-sky-wasm/tree/wasmgame): [Endless Sky](https://wasmga.me/games/endless-sky)
- [stk-code-wasm](https://github.com/wasmga-me/stk-code-wasm/tree/wasmgame): [SuperTuxKart](https://wasmga.me/games/supertuxkart)
- [supertux-wasm](https://github.com/wasmga-me/supertux-wasm/tree/wasmgame): [SuperTux](https://wasmga.me/games/supertux)
